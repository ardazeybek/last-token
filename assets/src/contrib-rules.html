Rules of the code

Four rules every change keeps

1 file

Standard library only

system/ctx.py stays one file. Nothing to pip install, ever.

exit 0

Hooks never crash

On any error a hook quietly steps aside. Your session always keeps running.

quota

Not tokens

Saves tokens but adds cache writes? That is a regression, not a win.

measured

Benchmark or it didn't happen

Every system change is run through the benchmark and logged as a round.
