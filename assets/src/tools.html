An honest look

Popular token tools, through the formula

Good projects by smart people. But most measure tokens, and tokens are the wrong unit for a subscription.

rtk

filters shell output before Claude sees it
Watch out

−1.2 % tokens in our benchmark, within noise. Read / Grep / Glob skip it.

small, safe

caveman

makes Claude answer in very short prose
Watch out

Right target, but output is only 8–13 % of quota. Answers get harder to read.

right aim, small share

context-mode

runs heavy tool work in a sandbox
Watch out

Keeps big outputs out. A different way of working: measure your quota.

can help

claudectx

trims CLAUDE.md and memory files
Watch out

Those are cheap cached reads. Cutting instructions can make Claude worse.

saves cheap tokens

compressors

rewrite or prune history mid-session
Watch out

Each rewrite moves the cached prefix. Pruning a warm cache cost +92 %.

the classic trap
Rule of thumb

If a tool changes what's already in your context mid-session, it is likely costing you quota. Last Token only touches it when the cache is already gone or must be rebuilt anyway, with no extra model call.
