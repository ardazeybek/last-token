Cutting tokens raised the bill by 69 %

Our own early version cut the context hard with many early compactions. Same 32-step task on Opus, compared with plain Claude Code.

Why it backfires

Every cut changes the start of the context, so the prompt cache has to be written again.

A cache write costs about as much as 30 cache reads. The tokens you save are cheap. The ones you cause are not.

Index: plain Claude Code = 100. Tokens 12.6M → 8.3M (−34 %). Cost $8.72 → $14.71 (+69 %).
