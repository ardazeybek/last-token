# Security policy

Last Token runs only on your computer. It has no server, no account and no telemetry: your notes, rules and archives stay in `~/.claude/last-token/` as plain Markdown files.

If you find a security problem (for example a hook that could run something it should not, or a way for one project's memory to leak into another), please do not open a public issue. Email **quantastudio.dev@gmail.com** with the steps to reproduce it. You will get an answer within a week.

Only the latest release gets security fixes.
